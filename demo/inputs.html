How to try it

  • Press "Send the application" with nothing filled in: a box lists the fields to fix, and focus moves to it. Each link puts you in its field.
  • Type abc in Start and press Tab: the error says how to fix it. Type 1:23.5: it says "Fixed".
  • Type 0911 234567 as the phone number and press Tab: it becomes +251911234567.
  • In the Amharic name field, type selam and a space with an English keyboard: a hint says how to switch the keyboard. It goes away when you type Amharic.
  • Turn on Caps Lock in the English text field: "Caps Lock is on" is shown and said, once.
  • Type something, then reload the page: it is still there, except the private support answer.
  • Turn off the network (or flight mode) and send: "Saved on this phone". Turn it back on: it is sent.
  • Press "Listen" under a text box to hear it in its language (only when this device or the server has a voice for it). Escape stops it.
  • Choose a date: the same date in the Ethiopian calendar appears under it.
