Reading and understanding

For blind, low-vision and low-literacy learners, and for coding lessons.

Code block

Who this helps: blind learners and coders. Speech mangles symbols and Python indentation; a Braille display needs real text.

for i in range(3):
    print(i)

Try it:

  • Press Tab to the code block, then use the Copy button.
  • Press Read line by line, then use the Up and Down arrow keys: each line is read with its indent.
  • Press Symbols as words to switch between "open bracket" and "(".
  • Press Play from 1:23 to start the lesson video (in the next example) at that point.

Code in sync with the video

Who this helps: blind learners following a coding video where the teacher types code on screen.

<h1>My first page</h1>
 
<h1>My first page</h1>
<p>Hello, world.</p>
 
<h1>My first page</h1>
<p>Hello, world.</p>
<img src="map.png" alt="Map of Addis Ababa">

Try it:

  • Play the video: when it reaches a snapshot's time, that snapshot shows "Now" and a screen reader hears "Code for 0:59 is ready" (once).
  • Press Play from 2:10 on the last snapshot: the video jumps there and that snapshot becomes "Now" (no announcement, because you chose it).

Diagram with a full description

Who this helps: blind learners, and anyone who finds a diagram hard to read.

Three boxes in a row, joined by arrows: Browser, Server, Database.

  1. The browser sends a request to the server (arrow to the right).
  2. The server asks the database for the data it needs (arrow to the right).
  3. The database sends the data back to the server (arrow to the left).
  4. The server sends a web page back to the browser (arrow to the left).

An image without alt text shows a warning on demo pages (the attribute show-warnings), so authors notice:

Try it:

  • Press Tab to "Full description" and press Enter (or tap it) to open the description under the image.
  • With a screen reader, the image is read by its alt text and the caption; the full description is real text with a list.

Tap a hard word for its meaning

Who this helps: learners who read with difficulty, and Deaf learners whose first language is sign language.

Your browser asks a server for the page. Good pages are accessible (this last word shows its window in Amharic).

Try it:

  • Press Tab to a dotted-underlined word and press Enter (or tap it): a small window shows its meaning in English and Amharic.
  • Press Escape (or Close): the window closes and you are back on the word.
  • A Listen button appears only if your device has a voice for that language.

Listen to a paragraph

Who this helps: learners who read with difficulty, and low-vision learners who do not use a screen reader.

A web page is a document. Your browser asks a server for it. Then the browser shows it on your screen.

ድረ-ገጽ ሰነድ ነው። አሳሽዎ ከአገልጋይ ይጠይቀዋል። ከዚያም አሳሹ በስክሪንዎ ላይ ያሳየዋል።

Try it:

  • Press Listen: the paragraph is read aloud and the sentence being read is highlighted and underlined. Press Stop or Escape to stop.
  • "Computer voice" tells you the voice is your device's, not a person's. If your device has no voice for a language (often Amharic), the paragraph says so instead of showing a button.

Instructions one step at a time

Who this helps: learners new to computers, and anyone overwhelmed by a wall of text.

  1. Open the website code.visualstudio.com in your browser.
  2. Press the big Download button for your computer (Windows, Mac or Linux).
  3. Open the file you downloaded. It is usually in your Downloads folder.
  4. Follow the installer: press Next on each screen, then Install.
  5. Open VS Code from your Start menu or Applications folder.
  1. በቪኤስ ኮድ ውስጥ አዲስ ፋይል ይክፈቱ።
  2. Ctrl እና S ቁልፎችን አንድ ላይ ይጫኑ።
  3. ለፋይሉ ስም ይጻፉ፤ ከዚያ አስቀምጥ የሚለውን ይጫኑ።

Try it:

  • Press Next: focus moves to the "Step 2 of 5" heading, so a screen reader reads where you are.
  • Tick "I did this step", then reload the page: your place and ticks are remembered in this browser.
  • Press Show all steps to see the whole list at once.

A simpler version of the same text

Who this helps: learners who read with difficulty, and learners reading in a second language.

When a user requests a web page, the browser transmits an HTTP request to the server, which processes it, retrieves any required resources, and returns an HTML document that the browser subsequently renders on the screen.

You ask for a web page. Your browser sends a message to a server. The server sends the page back. Your browser shows the page.

Try it:

  • Press Simple words: the same text appears in short sentences, one idea each. A screen reader hears "Simple version shown".
  • Reload the page: your choice is remembered in this browser.

Data, offline, dates and language

For learners on cheap phones and expensive data.

Data saver: know the size before you download

Who this helps: learners who pay for every megabyte of data.

Try it:

  • Read the size first: nothing is downloaded yet (this example asks the server for the size).
  • Press Tab to "Load it", then Enter: only now does the video load.
  • Or choose the text-only version, which is much smaller.

Offline status: online or not, and what still works

Who this helps: learners whose connection comes and goes.

Try it:

  • Turn off Wi-Fi or mobile data (or use airplane mode): the line changes to "You are offline" and says how many lessons are saved. A screen reader reads it once.
  • Save something with the next example, then open "Saved lessons".

Download later: download when you are online

Who this helps: learners who are offline now, or on expensive mobile data.

Try it:

  • Turn off the connection, then press "Download when I'm online": it waits in the queue.
  • Turn the connection back on: it downloads and says "Lesson 3 (demo file) is ready offline".
  • Use "Remove … from the queue" to cancel. On Android Chrome there is also "Only on Wi-Fi".

Section language: switch language for one section

Who this helps: learners who mix Amharic and English; Afaan Oromo and Arabic readers.

In this lesson you build one simple web page and check it with a screen reader.

በዚህ ትምህርት አንድ ቀላል ድረ-ገጽ ትሠራላችሁ፤ ከዚያም በስክሪን አንባቢ ትፈትሹታላችሁ።

Barnoota kana keessatti fuula weebii salphaa tokko ijaartee, dubbisaa iskiriinii (screen reader) tiin ni qorta.

في هذا الدرس تبني صفحة ويب بسيطة وتختبرها باستخدام قارئ الشاشة.

Try it:

  • Press Tab to the language buttons; each is written in its own language. Press Enter on "አማርኛ": only the Amharic version is shown, and a screen reader hears "Showing Amharic".
  • Choose "العربية": the text runs right to left.
  • Reload the page: your choice is remembered.

Display settings: make the page work for you

Who this helps: low-vision learners, learners with dyslexia, people sensitive to motion.

Example lesson text

A web page is a document that a browser shows. Headings help screen-reader users jump to the part they need.

ድረ-ገጽ አሳሽ የሚያሳየው ሰነድ ነው። ርዕሶች የስክሪን አንባቢ ተጠቃሚዎች ወደሚፈልጉት ክፍል እንዲዘሉ ይረዳሉ።

A link inside the lesson

Try it:

  • Press "Display settings": a dialog opens. Choose 150 %, "Wide" and "Yellow on black": only the example lesson text and the Fidel components change, not this page.
  • Press Escape: the dialog closes and focus goes back to the button. Reload: the settings are remembered.
  • Use "Reset" to go back to normal.
